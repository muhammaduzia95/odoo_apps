What it does

Developer Quick Access adds a search icon to the systray, shown whenever developer mode is active. Open it with the icon or the Alt+Shift+D shortcut, then type anything. Results open in a new browser tab, so your current view is left untouched. From a Sale Order? Type “purchase” and jump straight to Purchase Orders — no more digging through Settings → Technical.

ir.ui.menu · root

Apps, with their real icon

Sales, Purchase, POS, Apps — each shown with the icon you already recognise from the home screen.

ir.ui.menu

Technical & settings menus

Submenus are listed by their complete name, so you can see exactly where in the tree you are landing.

ir.actions.act_window

Window actions, intact

Actions open with their configured views and filters — the same thing you would get from the menu.

ir.model

Any model

Search by label or technical name. The model resolves to its window action, or to a generic view when none exists.

Install

  1. Copy dev_quick_access into your addons path.
  2. Update the apps list, then install Developer Quick Access.
  3. Enable developer mode in Settings.
  4. Click the bolt in the systray, or press Alt+Shift+D.

Good to know

  • The icon appears while developer mode is active.
  • Arrow keys move through results, Enter opens, Escape closes.
  • The active debug mode is carried into the new tab.
  • No server-side models added — the module depends on web alone.
